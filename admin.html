Quản lý thư mời

Tải nội dung, thêm nhạc nền và xuất bản đường link riêng cho khách mời.

01

Kết nối repository

Nhập thông tin repository GitHub mới của bạn.

Token chỉ dùng trong phiên trình duyệt hiện tại, không được ghi vào mã nguồn. Hãy giới hạn token vào repository này và cấp quyền Contents: Read and write.

02

Thiết lập thư mời

Mỗi sự kiện sẽ có một mã và một đường link riêng.

Chọn PDF hoặc bộ ảnh trang. Nếu chọn cả hai, hệ thống ưu tiên PDF. Nên giữ mỗi file dưới 15 MB để upload ổn định.
